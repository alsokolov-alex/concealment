# Проект "Маска"
## Описание:

Проект для чтения и обработки транзакций из файлов разных форматов (JSON, CSV, Excel).
Программа работает в интерактивном режиме: пользователь выбирает файл, фильтрует операции
по статусу, дате, валюте и слову в описании — и получает итоговую выборку в консоль.

Номера карт и счетов маскируются при выводе: видны только первые 6 и последние 4 цифры
карты (или последние 4 цифры счёта) — сырые реквизиты не попадают в консоль.

Проект включает набор тестов с моками и фикстурами, строгую типизацию (mypy)
и проверку стиля (flake8).
### Структура проекта

```
src/
 ├── masks.py — маскировка реквизитов (карты, счета)

 ├── test_utils.py — тесты функций из utils.py
 └── test_main.py — тесты диспетчера и main()
 ```

### Возможности
- Чтение транзакций из:
  - JSON;
  - CSV (с разделителем `;`);
  - Excel (`.xlsx`, `.xls`).
- Обработка ошибок: отсутствующие и повреждённые файлы возвращают пустой список,
  программа не падает.
- Логирование чтения файлов в `logs/utils.log`.
- Интерактивное меню:
  - выбор файла (JSON / CSV / XLSX);
  - фильтрация по статусу (EXECUTED, CANCELED, PENDING — регистр не важен);
  - сортировка по дате (по возрастанию / по убыванию);
  - фильтр по валюте (рублёвые транзакции);
  - поиск по слову в описании (библиотека `re`, без учёта регистра).
- Вывод транзакций в консоль: дата, описание, направление, сумма и валюта.
  Номера карт и счетов выводятся маскированными.### Модуль `processing`
 ### Модуль `processing`
Ключевые функции:

| Функция | Назначение |
| --- | --- |
| `filter_by_state(transactions, state)` | фильтр по статусу операции |
| `sort_by_date(records, descending)` | сортировка по полю `date` |
| `filter_by_currency(records, currency_code)` | фильтр по валюте (JSON и CSV/XLSX форматы) |
| `process_bank_search(data, search)` | поиск по описанию через `re` |
| `process_bank_operations(data, categories)` | подсчёт операций по категориям |

Поиск в `process_bank_search` и подсчёт в `process_bank_operations` реализованы
с помощью библиотеки `re`: регистр не учитывается, спецсимволы экранируются
через `re.escape`.

### Требования
- Python 3.11+

Рекомендуемые пакеты:

___pip install pytest pytest-mock pandas mypy flake8___

### Установка и запуск
1. Создайте и активируйте виртуальное окружение:
```
python -m venv .venv
.venv\Scripts\activate
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Запустите программу (из корня проекта):
```
python -m src.main
```
4. Запустите тесты:
```
pytest tests/ -v
```
5. Проверьте стиль кода:
```
flake8 src tests
```
6. Проверьте типизацию:
```
mypy src tests
```
