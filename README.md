# Проект "Сортировка информации по статусу и дате"

## Описание:

Проект "Сортировка..." - это приложение на Python для сортировки выводимой информации и дате. Пользователи могут
создавать новые записи, редактировать их, а также оставлять комментарии к записям других пользователей.

## Установка:

1. Особенной установки не требуется, достаточно загрузить функциональный модуль:
```
https://github.com/alsokolov-alex/concealment/blob/develop/src/processing.py
```
2. Зависимость направления сортировки по статусу:
```
'state': 'EXECUTED' Сортировка по убыванию (по умолчанию)
'state': 'CANCELED' Сортировка по возрастанию
```
3. Зависимость направления сортировки по дате:
```
descending=False по возрастанию (сначала старые)
descending=Truth по убыванию ( сначала новые)
```
4. Запуск на локальном сервере:
```
python main.py
```
## Использование:

1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.
3. Создайте новую запись в блоге или оставьте комментарий к существующей.
