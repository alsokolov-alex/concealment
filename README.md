# Банковские операции

Приложение для обработки финансовых транзакций из JSON-файла
с конвертацией валют через Exchange Rates Data API и маскировкой платёжных данных.
Реализовано структурированное логирование по модулям.

### Структура проекта
```
├── data/
│ └── operations.json # Исходные данные о транзакциях
├── logs/ # Папка для файлов логов (создаётся автоматически)
│ ├── masks.log # Логи модуля masks
│ └── utils.log # Логи модуля utils
├── src/
│ ├── init.py
│ ├── utils.py # Чтение JSON, базовая обработка
│ ├── external_api.py # Конвертация валют через API
│ └── masks.py # Маскировка номеров карт и счетов
├── tests/
│ ├── test_utils.py
│ ├── test_external_api.py
│ └── test_masks.py
├── .env.example # Шаблон переменных окружения (в репозитории)
├── .env # Локальные переменные (не коммитить!)
├── .gitignore
├── requirements.txt
└── README.md
```
### Установка

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение:
```
   python -m venv .venv
```
### Активируйте виртуальное окружение:
- Windows (PowerShell):
```
.venv\Scripts\Activate.ps1
```
- Windows (cmd):
```
.venv\Scripts\activate.bat
```
### Установите зависимости:
```
pip install -r requirements.txt
```
### Настройте переменные окружения:

- Скопируйте
```
.env.example
```
в
```
.env
```
- Откройте файл
```
.env
```
и укажите актуальный API-ключ для Exchange Rates Data:
```
EXCHANGE_RATES_API_KEY=ваш_новый_ключ
```
## Логирование
### Логирование реализовано для модулей ___utils___ и ___masks___:

- Отдельный логер для каждого модуля.
- Файлы логов создаются в папке ___logs/___ в корне проекта.
- ормат записи: ___%(asctime)s___ - ___%(name)s___ - ___%(levelname)s___ - ___%(message)s.___
- Уровень логирования: ___DEBUG___ и выше.
- При каждом запуске приложения логи перезаписываются (режим ___mode="w"___).

## Запуск тестов
Все тесты используют ___Mock___ и ___patch___, не делают реальных сетевых запросов и не зависят от содержимого ___.env.___

Запуск с проверкой покрытия кода:
```
pytest --cov=src --cov-fail-under=80
```
