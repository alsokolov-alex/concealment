# Банковские операции

Приложение для обработки финансовых транзакций из JSON-файла
с конвертацией валют через Exchange Rates Data API.

## Установка
1. Клонируйте репозиторий.
2. Создайте виртуальное окружение:

```
`python -m venv .venv`
```
3. Установите зависимости:
```
`pip install -r requirements.txt`
```
4. Скопируйте

```
.env.example`
```
в
```
`.env`
```
 и укажите свой API-ключ.
## Запуск тестов
```
pytest --cov=src
```
