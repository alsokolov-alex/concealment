# Проект "Маска"
## Описание:

Проект для чтения и обработки транзакций из файлов разных форматов (JSON, CSV, Excel). Включает полный набор тестов с моками, фикстурами и строгой типизацией.
### Структура проекта

```
src/
├── utils.py — функции чтения данных из JSON/CSV/Excel
└── main.py — точка входа, выбор формата и вывод транзакций
tests/
├── conftest.py — общие фикстуры (sample_transactions, sample_csv_content)
├── test_utils.py — тесты функций из utils.py
└── test_main.py — тесты диспетчера и main()
```

### Возможности
- Чтение транзакций из:
  - JSON
  - CSV (с разделителем ___`;`___)
  - Excel (.xlsx, .xls)
- Обработка ошибок:
  - отсутствующие файлы → пустой список
  - повреждённые JSON/CSV → пустой список
- Вывод транзакций в консоль
### Требования
- Python 3.11+

Рекомендуемые пакеты:
```
pip install pytest pytest-mock pandas mypy flake8
```
### Установка и запуск
1. Создайте и активируйте виртуальное окружение:
```
python -m venv .venv
.venv\Scripts\activate
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Запустите тесты:
```
pytest tests/ -v
```
4. Проверьте стиль кода:
```
flake8 src tests
```
5. Проверьте типизацию:
```

mypy src tests
```
