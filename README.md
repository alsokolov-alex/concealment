# Проект "Маскирование"
## Описание:

Проект "Маскирование" - это веб-приложение на Python для создания и проведения маскировки.
Пользователи могут создавать новые записи, редактировать их, а также оставлять комментарии
к записям других пользователей.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/alsokolov-alex/concealment/edit/develop
```
2. Запустите на локальном сервере:
```
python main.py
```
## Использование:

1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.
3. Создайте новую запись в блоге или оставьте комментарий к существующей. README.md).
