# Проект "Декоратор"
## Модуль "decorators"
## Описание
Декоратор ___log___ автоматически регистрирует детали выполнения функций: имя функции, результат или ошибку,
входные параметры. Это обеспечивает контроль и анализ поведения программы в процессе её выполнения.

## Возможности
Логирование начала и конца выполнения функции

При успешном выполнении — имя функции и результат:
```
my_function ok
```
При ошибке — имя функции, тип ошибки и входные параметры:
```
my_function error: тип ошибки. Inputs: (1, 2), {}
```
### Гибкий выбор места вывода:
- аргумент ___filename___ задан — логи пишутся в указанный файл;
- ___filename___ не задан — логи выводятся в консоль.
### Установка
Требуется Python 3.11+. Установите зависимости:
 
```
pip install -r requirements.txt
```

или вручную:

```
pip install pytest pytest-cov
```
### Пример использования
```
from src.decorators import log

@log(filename="mylog.txt")
def my_function(x, y):
    return x + y

my_function(1, 2)
```
В лог-файле ___mylog.txt___ появится:

```
my_function ok
```
Если функция завершится ошибкой:

```
@log(filename="mylog.txt")
def divide(x, y):
    return x / y

divide(1, 0)
```
в лог попадёт строка:

```
divide error: ZeroDivisionError. Inputs: (1, 0), {}
```
Исключение после логирования пробрасывается дальше — декоратор фиксирует ошибку, но не скрывает её.

При вызове без аргумента ___filename___ лог уходит в консоль:

```
@log()
def my_function(x, y):
    return x + y
```
___my_function(1, 2)   # в консоль: my_function ok___

### Тестирование
Тесты написаны с помощью ___pytest___. Проверяются разные сценарии:

- успешное выполнение функции с записью лога в файл;
- успешное выполнение с выводом лога в консоль;
- обработка исключений — проверка типа ошибки и входных параметров в логе;
- передача именованных аргументов ___(kwargs)___;
- сохранение метаданных исходной функции ___(__name__, __doc__).___

Для проверки вывода в консоль используется фикстура ___capsys___, перехватывающая стандартный вывод.

### Запуск тестов:

```
pytest
```
Все тесты завершаются успешно, функциональный код покрыт тестами на 80% и более.

Отчёт о покрытии в формате HTML:

```
pytest --cov=src --cov-report=html
```
После выполнения в корне проекта появится папка ___htmlcov___ — она включена в репозиторий.
Отчёт открывается в браузере через файл ___htmlcov/index.html.___
